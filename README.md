# 📊 لوحة تحكم تفاعلية | Responsive Admin Dashboard

لوحة تحكم (Admin Dashboard) متجاوبة بالكامل مصممة لإدارة البيانات والمبيعات، ومبنية باستخدام HTML و CSS و JavaScript بدون أي مكتبات خارجية معقدة.

---

## 🚀 المميزات الرئيسية (Key Features)

* **تصميم متجاوب بالكامل (Fully Responsive):** يدعم جميع الشاشات من الموبايل وحتى اللابتوب مع قائمة منسدلة (Hamburger Menu) للموبايل.
* **الوضع الليلي والنهار (Dark / Light Theme):** إمكانية التبديل بين الأوضاع مع حفظ ألوان مريحة للعين.
* **البحث والفلترة اللحظية (Real-Time Search):** فلترة جدول المستخدمين فورياً عند الكتابة في خانة البحث.
* **رسم بياني تفاعلي (Interactive Charts):** عرض إحصائيات المبيعات باستخدام مكتبة Chart.js.
* **كود نظيف ومنظم (Clean Code):** كود يتبع أفضل الممارسات في Vanilla JS وتصميم الـ UI/UX.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** بناء الهيكل الدلالي للموقع (Semantic Structure).
* **CSS3:** استخدام CSS Variables للوضع الليلي، وFlexbox / CSS Grid للتجاوب.
* **JavaScript (ES6+):** للتحكم في الأفعال اللحظية وتوليد البيانات ديناميكياً.
* **Chart.js:** للرسوم البيانية.
* **FontAwesome:** للأيقونات.
